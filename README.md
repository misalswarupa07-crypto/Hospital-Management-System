# Hospital Management System

A simple and responsive Hospital Management System developed using HTML, CSS, and JavaScript.

## Features

- Hospital dashboard
- Doctor, patient, appointment and bed statistics
- Patient registration
- Patient search
- Delete patient record
- New appointment booking
- Responsive design for desktop and mobile
- No external database required

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
Hospital-Management-System/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The Hospital Management System will open in your web browser.

## How to Upload to GitHub

1. Create a new GitHub repository named `Hospital-Management-System`.
2. Click **Add file → Upload files**.
3. Upload all four project files.
4. Enter the commit message: `Add Hospital Management System project`.
5. Click **Commit changes**.

## GitHub Pages

For an online version, go to:

**Settings → Pages → Deploy from a branch → main → /root → Save**

After deployment, GitHub will provide a website URL.
